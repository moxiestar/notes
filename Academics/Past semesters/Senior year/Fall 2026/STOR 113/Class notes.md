**What is a system?**

- **System:** collection of entities (people, parts, machines, etc) that act and interact together towards some logical end
  - We study systems to gain insights into the relationships between their component parts

**How do we make decisions about systems?**

- Experiment with the actual system
- Experiment with a physical or mathematical model of the system
  - Model should include only the most essential variables/factors 
  - Model should describe, predict, and control/optimize our variables

**Steps of using models**

1. Formulation
   - Gather data, identify questions, build model 
2. Solution 
   - Use analytical or numerical techniques to solve the problem
3. Analysis and interpretation
4. Implementation
